## Открытые вопросы (для grill-me перед установкой)

- Дистрибутив: k3s (рекомендация: минимальный оверхед, нативный containerd) vs microk8s vs kubeadm.
- CNI и ingress: стандартные для k3s (flannel + traefik/servicelb) достаточно для LAN-экспериментов.
- GPU: NVIDIA device plugin + настройка containerd runtime (nvidia-container-toolkit уже есть).
- Swap: отключить или kubelet с `--fail-swap-on=false`.
- Доступ: kubectl с хоста + kubeconfig; веб-доступ опционально (Lens/headlamp).
- Docker оставить для сборки образов или собирать в k8s (buildkit/kaniko)?
