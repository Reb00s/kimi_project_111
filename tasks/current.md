# Текущая задача

> Здесь всегда ТОЛЬКО ОДНА активная задача. Новая задача → эта уходит в archive/.

- **Название:** Тестовый стенд LLM на текущем сервере (подробности в `primary_task.md`)
- **Цель (1 строка):** Рабочий веб-сервис в локальной сети для загрузки и тестирования LLM-моделей (текст, кодинг, изображения, музыка/звук) на RTX 3060 12 GB с гибридной загрузкой GPU+RAM.
- **Критерии успеха:**
  - С любого устройства в LAN (телефон/ноутбук/планшет/ПК) открывается веб-интерфейс чата.
  - Текстовые и кодинг-модели отвечают с offload на GPU (подтверждено `nvidia-smi`).
  - Генерация изображений и звука работает через тот же веб-интранет (отдельные вкладки/сервисы).
  - Модель ~70B (Q4) грузится гибридом после апгрейда RAM.
  - Каждый этап завершён коммитом и пушем в `main`.

## Стек (решение 2026-09-09)

- **Текст/кодинг:** Ollama в Docker (сам управляет гибридным offload) + Open WebUI.
- **Изображения:** ComfyUI в Docker (GPU).
- **Музыка/звук:** AudioCraft (facebookresearch) в Docker, этап 5.
- Альтернативы (llama.cpp вручную, LocalAI) отклонены: выше сложность сопровождения при той же функциональности.

## План (этапы с чек-листом)

- [ ] **Этап 0 — Окружение.** `.env` из `.env.example`; установить `nvidia-container-toolkit`; docker-compose проект стенда; `nvidia-smi` виден из контейнера.
- [ ] **Этап 1 — GPU-стек текст/кодинг.** Ollama + Open WebUI в Compose; тестовая модель 7–8B полностью в GPU; `nvidia-smi` показывает загрузку VRAM; eval-набор: 5 тестовых промптов (вопрос, код, длинный контекст, русский язык, отказ/безопасность).
- [ ] **Этап 2 — Доступ из LAN.** Bind на 0.0.0.0, firewall (ufw), проверка с двух устройств; зафиксировать URL.
- [ ] **Этап 3 — Модельный зоопарк.** Pull 3–4 моделей: кодинг (Qwen2.5-Coder-14B), общая (Llama 3.1 8B), русская (Saiga/Llama рус.), малая для быстрых тестов (3–4B); таблица «модель → VRAM → скорость токен/с».
- [ ] **Этап 4 — Изображения.** ComfyUI в Docker + базовые workflow (SDXL/FLUX по VRAM); доступ из Open WebUI или отдельный порт.
- [ ] **Этап 5 — Музыка/звук.** AudioCraft (MusicGen) в Docker; тестовая генерация 30-сек трека; отдельный порт.
